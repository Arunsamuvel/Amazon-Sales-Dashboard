Amazon Sales Dashboard – README

Overview

The Amazon Sales Dashboard is an interactive Excel dashboard designed to analyze and visualize Amazon sales performance across different cities, states, and product categories.
It provides key business insights such as:

Total Sales
Total Units Sold
Number of Cities Covered
Product-wise Unit Distribution
City-wise Sales Trends
State-wise Sales Analysis

This dashboard is useful for:

Data Analyst Projects
Excel Portfolio Projects
Business Reporting
Sales Performance Tracking
Interview Demonstrations

Features
KPI Cards

The dashboard includes three major KPI indicators:

1. Sales

Displays total revenue generated.

2. Units

Shows total quantity of products sold.

3. Number of Cities

Represents the total cities contributing to sales.
